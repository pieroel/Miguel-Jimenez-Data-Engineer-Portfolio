# Sales Data Warehouse

This project builds a full ETL pipeline that loads sales data into Snowflake for analytics.

## Architecture
CSV → Python → Airflow → Snowflake → SQL Analytics

## Business Use Case
Enable leadership to track revenue by country and product.

## Tech
Python, Airflow, Snowflake, SQL

## Key Concepts
- Star schema
- ETL
- Orchestration
- Analytics-ready data
